# 💰 Quản Lý Hiệu Cầm Đồ

Dự án **Quản lý hiệu cầm đồ** được xây dựng nhằm hỗ trợ việc quản lý hợp đồng, tài sản cầm cố, và thông tin khách hàng một cách thuận tiện.  
Trang web cung cấp giao diện thân thiện, dễ sử dụng, phục vụ cho cả **người quản lý (Admin)** và **khách hàng**.

---

## 🌐 Công nghệ sử dụng
- **HTML5** – Xây dựng cấu trúc trang web  
- **CSS3** – Thiết kế giao diện và bố cục  
- **JavaScript (Vanilla JS)** – Xử lý tương tác và thao tác dữ liệu phía client

---

## ⚙️ Chức năng chính

### 👤 Người dùng (Khách hàng)
- Đăng ký hợp đồng cầm đồ  
- Tra cứu thông tin hợp đồng  
- Gửi liên hệ / phản hồi tới cửa hàng  

### 🧑‍💼 Quản trị viên (Admin)
- Tạo hợp đồng mới  
- Quản lý thông tin khách hàng và tài sản  
- Cập nhật trạng thái thu / chuộc  
- Quản lý liên hệ từ khách hàng  

---

## 🧭 Cấu trúc trang web

| Trang | Chức năng |
|-------|------------|
| **Home (Trang chủ)** | Giới thiệu tổng quan và điều hướng |
| **Giới thiệu (About)** | Thông tin về hiệu cầm đồ |
| **Loại tài sản (Category)** | Hiển thị danh mục tài sản nhận cầm |
| **Đăng ký hợp đồng (Register)** | Khách hàng điền thông tin đăng ký hợp đồng |
| **Tra cứu hợp đồng (Search)** | Tìm kiếm hợp đồng theo mã hoặc thông tin khách hàng |
| **Liên hệ (Contact)** | Gửi thông tin, phản hồi tới hiệu cầm đồ |
| **Admin Dashboard** | Giao diện dành cho quản trị viên, bao gồm các chức năng tạo/sửa/xóa hợp đồng và quản lý liên hệ |

---

## 🚀 Cách chạy dự án

1. Tải toàn bộ source code về máy.  
2. Giải nén (nếu cần).  
3. Mở file **`dashboard.html`** trong trình duyệt web (Chrome/Edge/Firefox).  
4. Sử dụng các tính năng có sẵn trên giao diện.

> 💡 Không yêu cầu cài đặt máy chủ hoặc cơ sở dữ liệu — chạy trực tiếp trên trình duyệt.
